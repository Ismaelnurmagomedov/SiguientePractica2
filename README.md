# PORTFOLIO PERSONAL

## DESCRIPCIÓN
Esta página web es un portfolio personal creado para la asignatura de TIC II. Su objetivo es presentar al alumno mediante una breve descripción personal a modo de currículum y mostrar un índice de las prácticas realizadas durante el curso. También incluye un avatar personalizado y la información de contacto académico.

# PORTFOLIO PERSONAL

## Descripción
Esta página web es un portfolio personal creado para la asignatura de TIC II. Su objetivo es presentar al alumno mediante una breve descripción personal a modo de currículum y mostrar un índice de las prácticas realizadas durante el curso. También incluye un avatar personalizado y la información de contacto académico.

## Estructura del proyecto
- `index.html`: página principal del portfolio con la presentación personal y el índice de prácticas.
- `css/estilos.css`: hoja de estilos propia.
- `img1/`: carpeta con las imágenes utilizadas en la web.
- `Ejercicio1/`: carpeta con los archivos de la primera práctica.
- `Salidasprofesionales/`: carpeta con los archivos de la segunda práctica.

## Tecnologías utilizadas
HTML5, CSS3 y Bootstrap 5.3.8 mediante CDN.

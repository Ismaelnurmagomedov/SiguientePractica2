# Diseña tu próximo paso

## Descripción
Esta página web compara tres opciones después de Bachillerato: el Grado en Inteligencia Artificial, el Grado en Ingeniería Informática y la oposición a Policía Nacional. Incluye información sobre cada opción, sus salidas profesionales y las formas de acceso.

## Estructura del proyecto
- `pag1.html`: página principal con la presentación de las tres opciones.
- `pag2.html`: tabla comparativa e información de cada opción.
- `pag3.html`: salidas profesionales, acceso y conclusión.
- `css/andaduras.css`: hoja de estilos propia.
- `img1/`: imágenes utilizadas en la web.

## Tecnologías utilizadas
HTML5, CSS3 y Bootstrap 5.3.8 mediante CDN.
